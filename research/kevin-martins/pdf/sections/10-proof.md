## Method

1. Listed every upload on both of Kevin's channels from April 27 to October 27, 2026 (41 found; Shorts and livestreams are not in any index I could reach), and prioritised tutorials, group-call segments and case studies with revenue.
2. Pulled each video's transcript through Perplexity's search index, which holds YouTube captions with timestamps. Direct access to YouTube is blocked from this cloud environment, and I didn't try to get around that.
3. Rebuilt the transcripts by script from the raw search results, exactly as returned (5,000+ caption windows across 380 videos, plus video descriptions), never retyped.
4. Cut every quote and prompt in this PDF from those windows by script; the build fails if any word differs. Exported documents straight from Google Drive.
5. For the Discord (section 7A), searched every published moment from inside it: wins-chat scrolls, the live session, the group call, member descriptions, and the tracked application links in the descriptions. Searched your Google Drive for group files (only the Seedance brief, which is public) and checked TrendTracker for ads (none).
6. Checked platform and legal claims (section 7B) against primary sources: TikTok, Meta and the FTC.
7. Ran six parallel research passes (about 200 searches) for this edition. Leads that couldn't be tied to the group were dropped, not used. They are listed below.

## What we could not get (and where it is)

- **The Discord's private channels.** Section 7A covers everything that has been published from inside the server. Not public: the full channel list beyond the wins chat, pinned prompts, the new FSE app, unpublished call recordings and member chat. Section 7A ends with the two ways a member can add them.
- **Kevin's context prompt.** He says it is “linked right here” (Jun 19), but his descriptions as indexed carry only the application link, a case-study link and his Instagram. Probably an on-screen link or member-only. If you get it, save it to your Drive and it can be added word for word, like P12.
- **Prompts shown only on screen or kept for members:** the Kling prompt structure, full image prompts, Elias's 321 prompt and the run-two prompts. Captions only record speech, and none of these was read aloud in any window we retrieved. Kevin also shows the Discord itself on screen (the wins chat, and in places its channel list). Two ways to read those screens: add a Gemini API key to this cloud environment (Google's model watches the video itself; the `watch` tool in your repo is set up for it), or set up Remote Control on your own computer with a folder (Claude desktop app → Settings → Claude Code → Remote Control), so frames can be pulled there, where YouTube isn't blocked.
- **Transcript coverage** ran from about 25% (the 3.5-hour course) to near-complete (short videos). The likeliest spot for a spoken Kling prompt (about 18:20–18:50 of the Jun 19 tutorial) never came back in four tries.
- **Speaker labels** in group calls are inferred from context, not captioned.
- **Today's price.** The only figure is Pedro's $3,000, from when he joined.
